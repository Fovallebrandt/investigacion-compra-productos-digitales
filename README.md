La pregunta rectora es: **¿qué tiene que ocurrir para que una persona que consume contenido digital gratuito decida pagar por un producto educativo?**

Los informes separan **hechos observados**, **inferencias** e **hipótesis**. Un precio anunciado no equivale a ventas; tampoco el tráfico o las visualizaciones gratuitas prueban demanda pagada.
