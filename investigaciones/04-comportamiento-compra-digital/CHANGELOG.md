# Cambios — comportamiento de compra digital

## 0.2.0 — 2026-10-22 20:08 UTC

- Se retiró la estimación de conversión de contenido gratuito a pagado como objetivo de esta iteración: no hay evidencia pública comparable suficiente.
- Se añadió una recomendación operativa para el checkout de un programa de respiración de siete días en México, Chile y España.
- Se compararon Hotmart, Teachable Pay, Mercado Pago, Webpay/Transbank y Stripe, con sus límites de disponibilidad y operación.
- Se acotó el uso de entrevistas a una herramienta opcional de lenguaje y objeciones, no a una estimación de demanda.

## 0.1.0 — 2026-10-22 16:10 CLST

- Se creó la primera síntesis comparativa para México, Chile, España, Colombia, Argentina y Brasil.
- Se documentaron 25 fuentes de contexto, comportamiento, pago y confianza.
- Se separó de manera explícita el e-commerce general de la compra de productos digitales.
- Se declararon como pendientes las entrevistas y la medición de conversión desde gratuito a pagado.
